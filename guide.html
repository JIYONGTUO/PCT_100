🛠️ 开发环境搭建

1

安装 VS Code + PlatformIO

下载安装 VS Code，在左侧扩展市场搜索 "PlatformIO IDE" 并安装。安装完成后左侧活动栏出现蚂蚁图标即成功。

2

安装 USB 转串口驱动

根据开发板搭载的 USB 芯片安装对应驱动：

  • CP2102 → Silicon Labs 官网下载 CP210x 驱动
  • CH340 → 南京沁恒官网下载 CH340 驱动
3

配置 platformio.ini

在项目根目录创建配置文件：

[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
lib_deps =
    olikraus/U8g2 @ ^2.34.0
    adafruit/Adafruit NeoPixel @ ^1.12.0
    paulstoffregen/OneWire @ ^2.3.0
    milesburton/DallasTemperature @ ^3.9.0
    knolleary/PubSubClient @ ^2.8
    bblanchon/ArduinoJson @ ^6.21.0
monitor_speed = 115200

📥 烧录固件

1

连接开发板

USB 数据线连接 ESP32 到电脑，VS Code 底部状态栏选择对应串口（如 COM3 / ttyUSB0）。

2

编译与上传

点击 PlatformIO 工具栏 ✓ Build 编译项目，编译通过后点击 → Upload 烧录。

若出现 "Failed to connect to ESP32"，在上传时按住 BOOT 键直到出现 "Connecting..."。

3

查看串口输出

点击 🔌 Serial Monitor（波特率 115200），正常启动后应看到系统初始化日志和 WiFi 状态信息。

烧录成功！观察到 OLED 点亮并显示启动画面，WS2812 七彩闪烁后进入正常指示状态，即烧录完成。

📡 WiFi 配网

设备首次使用或更换网络时，通过串口命令配置 WiFi：

1

扫描附近网络

scan

返回可用 WiFi 热点列表及信号强度 (dBm)。

2

连接指定网络

connect MyWiFi mypassword123

凭据自动保存至 NVS，断电不丢失，下次开机自动连接。

3

验证连接状态

ip

返回 IP（如 192.168.1.105），OLED 第 5 行同步显示。

更换网络时先用 forget 清除凭据，再重新 connect。用 disconnect 可临时断开。

☁️ MQTT 配置

1

配置服务器信息

cfg_mqtt 47.98.170.180 8081 username password device_001

参数：服务器IP、端口、用户名、密码、设备ID。无认证时可填任意占位符。

2

确认配置已保存

cfg_show
3

远程控制测试

使用 MQTTX / MQTT.fx 客户端发送指令：

📤 发布主题: chemctrl/device_001/command
📤 消息内容: {"cmd":"set_relay","light":1,"fan":0}

📥 订阅主题: chemctrl/device_001/status  (查看设备上报)
