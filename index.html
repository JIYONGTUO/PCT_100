📋 产品总览

PCT-100 是一款面向高校化工自动化与物联网教学的ESP32 综合实训装置，集成了多传感器数据采集、继电器自动控制、OLED 中文显示、WiFi 智能配网、MQTT 远程监控与 HTTP REST API 等完整功能链路。装置采用模块化设计，从底层硬件到云端通信，为学习者提供从入门到精通的全栈嵌入式开发体验。

▲ PCT-100 系统架构示意图

🌡️

多传感器融合

集成 GL5516 光敏电阻（ADC 模拟采集）与 DS18B20 温度传感器（1-Wire 数字总线），双协议实现光照 lux 照度与温度的高精度实时监测。

⚙️

智能滞回控制

光照 / 温度双阈值自动触发继电器，内置 0.5°C 滞回控制算法，避免执行器在临界值附近频繁切换，有效保障设备寿命。

🔄

自动 / 手动双模式

一键切换控制模式。自动模式按传感器阈值联锁控制；手动模式通过按键循环切换灯与风扇的开关组合（00→01→10→11）。

📡

WiFi 智能配网

NVS 非易失存储记忆 WiFi 凭据（断电不丢失），状态机管理连接流程，支持扫描、选择、输密、自动重连全流程。

☁️

MQTT 远程监控

JSON 格式 MQTT 通信，每 10 秒自动上报完整状态。支持远程下发继电器开关、模式切换、阈值修改等控制指令。

🌐

HTTP REST API

内置 Web 服务器，提供 /api/status、/api/mode、/api/led 等 9 个端点。浏览器即可实时查看状态并远程控制设备。

💡

WS2812 智能灯效

6 种灯效按优先级自动切换：严重报警→光照越界→温度越界→MQTT未连→WiFi未连→全正常，一眼判断系统状态。

📺

OLED 中文显示

SH1106 128×64 屏幕 + 文泉驿字体，5 行信息实时展示模式、光照、温度、继电器状态及 WiFi IP，一目了然。

🔌 硬件规格与引脚定义

电气参数

  • 主控供电：5V USB 或 5V 引脚输入，板载 AMS1117-3.3V 稳压
  • 继电器模块：5V 供电，光耦隔离，低电平触发（控制端 HIGH 有效）

  • WS2812：3.3V 信号电平兼容，建议串联 470Ω 限流电阻

📡 传感器系统

光照检测 — GL5516 光敏电阻

光敏电阻通过串联 10kΩ 分压电路接入 GPIO1（ADC1_CH0），系统依次进行 ADC 采集→电压换算→电阻反算→照度百分比计算，最终输出 lux 照度值。自动模式下默认阈值 150 lux。

  • ADC 分辨率：12-bit（0 ~ 4095）
  • 参考电压：3.3V
  • 默认阈值：150 lux（可通过 MQTT 或串口命令远程修改）
  • 超阈值动作：自动开启照明灯（GPIO6 HIGH）

温度检测 — DS18B20 数字温度传感器

采用 OneWire + DallasTemperature 库驱动，连接至 GPIO10。12-bit 精度（分辨率 0.0625°C）。自动模式下采用 0.5°C 滞回控制：温度 >33°C 开风扇，<32.5°C 关风扇，避免临界点频繁启停。

  • 测温范围：-55°C ~ +125°C
  • 精度：±0.5°C（-10°C ~ +85°C）
  • 默认阈值：33°C，滞回区间 0.5°C
  • 超阈值动作：自动开启散热风扇（GPIO7 HIGH）

🎛️ 控制与输出

自动模式（默认）

系统上电后自动进入。两个控制通道相互独立运行：

  • ☀️ 光照 > 150 lux → 开灯（GPIO6 HIGH） / ≤ 150 lux → 关灯（LOW）
  • 🌡️ 温度 > 33°C → 开风扇（GPIO7 HIGH） / ≤ 32.5°C → 关风扇（LOW）

阈值可通过串口命令 set_threshold <light> <temp> 或 MQTT set_threshold 远程修改。

手动模式

长按 KEY2（约 2 秒）切换自动/手动。手动模式下短按 KEY2 循环切换组合：

00（全关） ▸ 01（仅灯开） ▸ 10（仅风扇开） ▸ 11（全开） ▸ 00 循环

总开关（KEY1）

KEY1 为自锁按键，作为系统总使能。断开（低电平）时系统休眠：所有继电器关闭、OLED 熄屏、LED 停止。合上后恢复正常运行。

🖥️ 显示与交互

OLED 显示布局

SH1106 128×64 OLED + U8g2 库 + 文泉驿 12px 中文字体，5 行信息：

  1. 模式 + 总闸：自动/手动 + KEY1 状态
  2. 光照 / 阈值：实时 lux 值 + 设定阈值（超阈值 ⚠️ 报警）
  3. 温度 / 阈值：实时 °C + 设定阈值（超阈值 ⚠️ 报警）
  4. 灯 + 风扇：两路继电器开关状态
  5. WiFi IP：当前局域网 IP，未连接显示"WiFi:未连接"

按键操作

按键操作方式功能说明

KEY2短按（< 1s）手动模式下循环切换灯/风扇组合

WS2812 灯效优先级

  1. 🔴🟢🔵 严重报警（灯+风扇均超阈值）— 快速闪烁
  2. 🔴🟢🔵 光照越界 — 慢闪
  3. 🔴🟢🔵 温度越界 — 长亮
  4. 🔴🟢 MQTT 未连接 — 渐变切换
  5. 🔴🟢 WiFi 未连接 — 交替闪烁
  6. 🌈 全部正常 — 彩虹呼吸效果

📐 外形尺寸与安装

  • 核心板尺寸：ESP32-DevKitC 约 48mm × 28mm
  • 建议底板：自行设计或选用洞洞板固定核心板与外设模块
  • 继电器模块：标准 2 路继电器扩展板，5V 供电
  • OLED 模块：0.96 寸 128×64 I²C，4 针接口
  • 安装建议：各模块固定于绝缘底板，杜邦线连接时注意区分 3.3V 与 5V 供电
提示：建议在底板背面或侧面留出 USB 接口位置，方便后续烧录固件与串口调试。

🔧 维护保养与故障处理

常见问题排查

现象可能原因解决方法
OLED 无显示I²C 接线错误 / 地址不匹配检查 SDA/SCL 是否接反，确认 0x3C
DS18B20 读数异常缺少上拉电阻 / 接线松动VCC-DATA 并联 4.7kΩ，检查连接
光敏读数始终为 0ADC 引脚接错 / 分压开路确认光敏接 GPIO1，检查串联电阻
继电器不动作供电不足 / 触发逻辑相反确认 5V 供电，控制端 HIGH 有效
WiFi 无法连接SSID/密码错误 / 信号弱先用 scan 确认网络，重新 connect
MQTT 连接失败服务器地址错误 / 网络不通检查 IP 端口，确认可访问公网
WS2812 不亮信号电平不足 / 电源不稳3.3V 通常可直接驱动，必要时加电平转换
