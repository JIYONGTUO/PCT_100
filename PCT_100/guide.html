快速上手指南

从开箱到运行的完整步骤，15 分钟搭建您的化工控制实训平台

准备工作

在开始之前，请确认您已备齐以下硬件与软件：

硬件清单

  • ESP32-DevKitC 开发板 × 1
  • SH1106 OLED 128×64 I2C 显示屏 × 1
  • GL5516 光敏电阻 + 10kΩ 分压电阻 × 1
  • DS18B20 温度传感器 + 4.7kΩ 上拉电阻 × 1
  • 2 路继电器模块（5V 光耦隔离）× 1
  • WS2812 RGB LED × 1
  • 自锁按键（KEY1）+ 轻触按键（KEY2）× 各 1
  • USB 数据线（支持数据传输）× 1
  • 杜邦线若干、洞洞板或面包板 × 1

软件清单

  • Visual Studio Code
  • PlatformIO IDE 插件
  • CH340 / CP2102 驱动（根据开发板 USB 转串芯片安装）

开发环境搭建

1

安装 VS Code 与 PlatformIO

下载安装 Visual Studio Code，在扩展市场中搜索并安装 "PlatformIO IDE" 插件。安装完成后左侧活动栏会出现 PlatformIO 蚂蚁图标。

2

安装 USB 转串驱动

根据您的 ESP32 开发板搭载的 USB 芯片安装对应驱动：

  • CP2102（Silicon Labs）— 官网下载 CP210x 驱动
  • CH340（南京沁恒）— 官网下载 CH340 驱动
3

配置 platformio.ini

在项目根目录创建 platformio.ini，内容如下：

[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
lib_deps =
    olikraus/U8g2 @ ^2.34.0
    adafruit/Adafruit NeoPixel @ ^1.12.0
    paulstoffregen/OneWire @ ^2.3.0
    milesburton/DallasTemperature @ ^3.9.0
    knolleary/PubSubClient @ ^2.8
    bblanchon/ArduinoJson @ ^6.21.0
monitor_speed = 115200

烧录固件

1

连接开发板

使用 USB 数据线将 ESP32 开发板连接至电脑。在 VS Code 底部状态栏选择正确的串口（如 COM3 或 /dev/ttyUSB0）。

2

编译与上传

点击 PlatformIO 工具栏的 Build（对勾图标）编译项目。编译成功后点击 Upload（箭头图标）将固件烧录至 ESP32。

若上传失败提示 "Failed to connect to ESP32"，请在点击 Upload 的同时按住开发板上的 BOOT 按键，直到出现 "Connecting..." 提示后松开。

3

查看串口输出

点击 PlatformIO 工具栏的 Serial Monitor（插头图标），波特率设置为 115200。正常启动后应看到系统初始化日志与 WiFi 连接状态。

WiFi 配网

设备首次使用或更换网络环境时，需要通过串口命令配置 WiFi。

1

扫描附近网络

在串口监视器中输入命令：

scan

设备将返回附近可用的 WiFi 热点列表及其信号强度。

2

连接指定网络

输入以下命令连接您的 WiFi（将 ssid 和 password 替换为实际值）：

connect MyWiFi mypassword123

连接成功后，设备会将 WiFi 凭据保存至 NVS，断电不丢失。下次开机将自动尝试连接。

3

验证连接

输入命令查看当前 IP：

ip

若返回形如 192.168.1.105 的地址，说明 WiFi 连接成功。此时 OLED 第 5 行也会显示该 IP。

提示：若需更换网络，使用 forget 命令清除已保存的凭据，然后重新 connect。

MQTT 配置

MQTT 配置用于远程监控与控制设备，同样通过串口命令完成。

1

配置 MQTT 服务器

输入以下命令配置服务器信息：

cfg_mqtt 47.98.170.180 8081 username password device_001

参数依次为：服务器地址、端口、用户名、密码、设备 ID。若服务器无认证，用户名和密码可填任意占位符。

2

查看配置

输入命令确认配置已保存：

cfg_show
3

远程控制测试

使用 MQTT 客户端（如 MQTT.fx、MQTTX）订阅控制主题并发送 JSON 指令：

主题: chemctrl/device_001/command
内容: {"cmd":"set_relay","light":1,"fan":0}

设备收到指令后将立即切换继电器状态，并上报最新状态至 chemctrl/device_001/status。

功能验证

完成以上步骤后，按照以下清单逐项验证设备功能：

验证项操作方法预期结果
系统启动 合上 KEY1，观察 OLED 与 LED OLED 显示启动画面，WS2812 七彩闪烁后进入状态指示
传感器读数 观察 OLED 第 2、3 行 光照显示为合理 lux 值，温度显示为环境温度
自动模式 用手遮挡光敏电阻 / 加热 DS18B20 光照低于阈值灯灭，高于阈值灯亮；温度超 33°C 风扇启动
手动模式 长按 KEY2 切换手动，短按循环 继电器按 00→01→10→11 循环切换
WiFi 连接 查看 OLED 第 5 行 显示当前局域网 IP 地址
HTTP API 浏览器访问 http://<ip>/api/status 返回 JSON 格式的传感器与继电器状态
MQTT 上报 使用 MQTT 客户端订阅状态主题 每 10 秒收到一次状态 JSON
恭喜！若以上验证项全部通过，说明您的 PCT-100 实训装置已成功搭建并开始运行。
