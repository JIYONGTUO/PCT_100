PCT-100 化工控制实训装置

面向化工自动化教学、物联网实训、智能控制研发的 ESP32 综合实训平台

产品总览

PCT-100 是一款基于 ESP32 微控制器的化工控制实训装置，集成了多传感器数据采集、继电器自动控制、OLED 本地显示、WiFi 无线配网、MQTT 远程通信等功能模块。装置在设计上充分考虑了高校化工自动化与物联网教学的实际需求，提供了从底层硬件到云端通信的完整实训链路，帮助学习者系统掌握嵌入式开发、传感器应用、工业通信协议等核心技能。

多传感器融合

集成 GL5516 光敏电阻与 DS18B20 温度传感器，支持 ADC 模拟采集与 1-Wire 数字总线双协议，实现光照 lux 照度与温度的高精度监测。

智能自动控制

光照 / 温度双阈值自动触发继电器，内置滞回控制算法，避免设备在临界值附近频繁切换，保障执行器寿命。

多模式控制

支持自动 / 手动模式一键切换。自动模式按传感器阈值执行；手动模式通过按键循环控制灯和风扇的开关组合。

WiFi 智能配网

NVS 非易失存储断电记忆 WiFi 凭据，串口交互式配网，状态机管理连接流程，支持扫描、选择、输入密码、自动重连。

MQTT 远程监控

基于 JSON 格式的 MQTT 通信，每 10 秒自动上报状态，支持远程下发开关、模式切换、阈值修改等指令。

HTTP REST API

内置 Web 服务器，提供 /api/status、/api/mode、/api/led 等端点，浏览器即可实时查看状态并远程控制设备。

WS2812 状态指示

6 种灯效模式按优先级自动切换，涵盖正常、WiFi 未连接、MQTT 未连接、温度/光照越界、严重报警等状态。

OLED 中文显示

SH1106 128×64 显示屏配合文泉驿字体，实时展示模式、光照、温度、继电器状态、WiFi IP 等 5 行关键信息。

典型应用场景

  • 高校化工自动化课程教学与实验实训
  • 物联网传感器数据采集与无线传输实验
  • 智能照明与温控系统原型开发
  • MQTT / HTTP 工业通信协议学习
  • 嵌入式系统课程设计与毕业设计
  • 远程监控与自动化控制科研平台

硬件规格与引脚定义

PCT-100 核心控制板采用 ESP32-DevKitC 开发板（240MHz 双核、520KB SRAM、4MB Flash），配合外设模块组成完整实训系统。以下为各功能模块与 GPIO 引脚映射关系。

电气参数

  • 主控供电：5V USB 或 5V 引脚输入，板载 AMS1117-3.3 稳压
  • 继电器模块：5V 供电，光耦隔离，低电平触发（控制端 HIGH 有效）
  • OLED 模块：3.3V 供电，I2C 地址 0x3C
  • DS18B20：3.3V 供电，建议并联 4.7kΩ 上拉电阻
  • WS2812：3.3V 信号电平兼容，建议串联 470Ω 限流电阻

传感器系统

光照检测（GL5516 光敏电阻）

光敏电阻通过分压电路接入 GPIO1（ADC1_CH0），系统读取 ADC 原始值后依次进行电压换算、电阻换算、照度百分比计算，最终输出 lux 照度值。默认自动模式阈值设为 150 lux，当环境光照超过阈值时自动开启照明灯，低于阈值时关闭。

  • ADC 分辨率：12-bit（0 ~ 4095）
  • 参考电压：3.3V
  • 默认阈值：150 lux（可通过 MQTT / 串口命令远程修改）

温度检测（DS18B20）

DS18B20 采用单总线协议，通过 OneWire 库与 DallasTemperature 库驱动，连接至 GPIO10。传感器以 12-bit 精度读取温度，分辨率为 0.0625°C。自动模式下，当温度高于 33°C 时开启风扇，低于 32.5°C（滞回 0.5°C）时关闭，避免风扇频繁启停。

  • 测温范围：-55°C ~ +125°C
  • 精度：±0.5°C（-10°C ~ +85°C 范围内）
  • 默认阈值：33°C（可通过 MQTT / 串口命令远程修改）
  • 滞回区间：0.5°C

控制与输出

自动模式

系统上电后默认进入自动模式。自动模式逻辑如下：

  • 光照 > 150 lux → 开启灯（GPIO6 HIGH）
  • 光照 ≤ 150 lux → 关闭灯（GPIO6 LOW）
  • 温度 > 33°C → 开启风扇（GPIO7 HIGH）
  • 温度 ≤ 32.5°C → 关闭风扇（GPIO7 LOW）

两个控制通道相互独立，阈值可通过串口命令 set_threshold <light> <temp> 或 MQTT 远程修改。

手动模式

长按 KEY2（约 2 秒）切换自动 / 手动模式。手动模式下，短按 KEY2 循环切换灯和风扇的组合状态：

00（全关）→ 01（灯开）→ 10（风扇开）→ 11（全开）→ 00（全关）

总开关（KEY1）

KEY1 为自锁按键，作为系统总开关使用。当 KEY1 断开（低电平）时，系统进入休眠状态，所有继电器关闭、OLED 熄屏、LED 指示停止。KEY1 合上后系统恢复正常工作。

网络通信

WiFi 管理

WiFi 管理模块采用状态机设计，支持以下串口命令：

  • scan — 扫描周围可用 WiFi 热点
  • connect <ssid> <password> — 连接指定网络
  • ip — 查看当前 IP 地址
  • forget — 清除已保存的 WiFi 凭据
  • disconnect — 断开当前连接

WiFi 凭据保存在 ESP32 NVS 中，断电不丢失。开机后自动尝试连接已保存的网络。

MQTT 通信

默认 MQTT 服务器地址为 47.98.170.180:8081，协议版本 MQTT 3.1.1。设备 ID 可自定义，主题格式如下：

  • 状态上报：chemctrl/{device_id}/status（每 10 秒自动推送 JSON）
  • 控制接收：chemctrl/{device_id}/command（订阅远程指令）

支持的远程命令包括：

set_relay <light> <fan>   // 设置继电器开关
set_mode <auto/manual>      // 切换自动/手动模式
get_status                    // 立即上报一次状态
set_threshold <light> <temp> // 修改光照/温度阈值
reboot                        // 重启设备

显示与交互

OLED 显示内容

显示屏为 SH1106 128×64 单色 OLED，通过 U8g2 库驱动，使用文泉驿 12px 字体支持中文显示。界面布局为 5 行信息：

  1. 模式 + 总闸：显示当前自动/手动模式，以及 KEY1 总开关状态
  2. 光照 / 阈值：实时 lux 照度与设定阈值，越界时显示感叹号报警
  3. 温度 / 阈值：实时温度与设定阈值，越界时显示感叹号报警
  4. 灯 + 风扇：显示两个继电器的开关状态
  5. WiFi IP：显示当前连接的网络 IP 地址，未连接时提示“WiFi:未连接”

按键操作

按键操作功能
KEY1拨动自锁开关系统总使能 / 休眠
KEY2短按（< 1s）手动模式：循环切换灯/风扇组合
KEY2长按（≈ 2s）切换自动 / 手动模式

WS2812 灯效状态

1 颗 WS2812 RGB LED 以 6 种灯效按优先级指示系统状态：

  1. 严重报警（灯+风扇均越阈值）— 红绿蓝快速闪烁
  2. 光照越界 — 红绿蓝慢闪
  3. 温度越界 — 红绿蓝长亮
  4. MQTT 未连接 — 红→绿→灭→蓝渐变
  5. WiFi 未连接 — 红绿交替闪烁
  6. 全部正常 — 彩虹呼吸渐变

外形尺寸与安装

  • 核心板尺寸：ESP32-DevKitC 约 48mm × 28mm
  • 建议底板：自行设计或选用洞洞板固定核心板与外设模块
  • 继电器模块：标准 2 路继电器扩展板，5V 供电
  • OLED 模块：0.96 寸 128×64 I2C 模块，4 针接口
  • 安装建议：核心板与外设模块固定于绝缘底板，杜邦线连接时注意区分 3.3V 与 5V 供电
提示：建议在底板背面或侧面留出 USB 接口位置，方便后续烧录固件与串口调试。

维护保养与故障处理

常见问题排查

现象可能原因解决方法
OLED 无显示 I2C 接线错误 / 地址不匹配 检查 SDA/SCL 是否接反，确认地址为 0x3C
DS18B20 读数异常 缺少上拉电阻 / 接线松动 VCC 与 DATA 之间并联 4.7kΩ 电阻，检查接线
光敏读数始终为 0 ADC 引脚接错 / 分压电阻开路 确认光敏电阻接至 GPIO1，检查串联电阻
继电器不动作 供电不足 / 触发逻辑相反 确认继电器模块为 5V 供电，控制端 HIGH 有效
WiFi 无法连接 SSID/密码错误 / 信号弱 使用 scan 确认网络可见，重新 connect
MQTT 连接失败 服务器地址错误 / 网络不通 检查 IP 和端口，确认设备可访问公网
WS2812 不亮 信号电平不足 / 电源不稳 3.3V 信号通常可直接驱动，必要时加电平转换

固件升级

通过 USB 连接 ESP32 开发板，在 PlatformIO 中点击 Upload 即可烧录最新固件。烧录前请确保 KEY1 总开关处于合上（使能）状态，以便观察升级后的运行效果。
